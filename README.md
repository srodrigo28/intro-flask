# 🚀 Introdução ao Python Flask

Uma página didática, responsiva e interativa para apresentar os primeiros conceitos do **Python Flask** em uma trilha de leitura sequencial.

## Novo

O projeto foi criado como uma experiência visual em HTML, CSS e JavaScript, com menu lateral, seções organizadas, exemplos de código, modais explicativos e botões para copiar trechos rapidamente.

## ✨ Visão geral

Este material funciona como uma introdução guiada ao Flask, começando pelo contexto do framework e avançando até a estrutura básica de uma aplicação web.

A navegação foi pensada para acompanhar a ordem natural de aprendizagem:

1. 🌟 Visão geral da trilha
2. 📚 Como o Flask surgiu
3. 🧱 O que um framework faz
4. 🗂️ Estrutura base de um projeto Flask
5. 🛣️ Rotas, controllers e templates
6. ✅ Fluxo completo da aplicação

## 🧠 O que você aprende

- O que é o Flask e por que ele é tão usado no ecossistema Python
- Como um framework ajuda a organizar uma aplicação web
- Qual é a estrutura inicial de pastas em um projeto Flask
- Como rotas se conectam com controllers e templates
- Como o Jinja permite criar páginas dinâmicas
- Como o navegador, o Flask e os arquivos HTML trabalham juntos

## ▶️ Como executar

Como o projeto é uma página estática, não é necessário instalar dependências.

Basta abrir o arquivo `index.html` diretamente no navegador:

```text
index.html
```

Também é possível usar uma extensão como **Live Server** no VS Code para visualizar a página com recarregamento automático.

## 📌 Destaques do conteúdo

O `index.html` apresenta exemplos práticos de uma aplicação Flask organizada em camadas, incluindo:

```text
app/
├── __init__.py
├── controllers/
│   └── page_controller.py
├── routes/
│   └── page_routes.py
├── static/
│   └── style.css
└── templates/
    ├── base.html
    ├── home.html
    └── about.html
```

Esses exemplos ajudam a visualizar a separação entre rota, regra de negócio e template.

## 🎯 Objetivo

O objetivo deste projeto é transformar a introdução ao Flask em uma experiência mais clara, bonita e fácil de acompanhar.

Em vez de apenas mostrar código solto, a página organiza o conteúdo em uma sequência lógica, ajudando quem está começando a entender o papel de cada arquivo dentro de uma aplicação web.
